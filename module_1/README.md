# Module 1: The ESP8266 Attack Surface

1. Arduino IDE with ESP8266 board support installed 
2. Wireshark (https://www.wireshark.org/#download)
3. Nmap (https://nmap.org/download#windows)
4. USB cable and computer.
5. Your personal Wi-Fi router.
6. Personal laptop running Windows.
